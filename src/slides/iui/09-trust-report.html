C3 Rule-based trust report

Written rules set the reference verdict

The report runs a fixed set of checks, so orchestration shapes the conversation, not the verdict. The first match among 15 ordered rules in the trust profile sets the verdict and its confidence.

1

Declarations and signatures come first

2

A place or date contradicting the claim gives Misleading context

3

Pixels come last

Else

The default is Uncertain

Pixels alone never yield authentic or high confidence, as detector outputs can mislead claim verification.

Safeguards. AMITO must never identify people, must base statements on check results and must not overstate them.

Four prepared demo scenarios

An iPhone photo with GPS in Genoa is described as "taken in Valencia, Spain, last week". Place and date both contradict the file.
