Source. AMITO, Oct 2026. Providers and settings as in its configuration template.

  • About 25 seconds.
  • Anyone can self-host AMITO and exchange or extend its parts. Any LLM with tool calling can be integrated, locally through Ollama or through a hosted API such as Anthropic's or OpenAI's. With a local model, images need not reach an LLM provider. Switching is one setting in the configuration.
  • New forensic models join the detection service behind a shared interface. The agent orchestrates new tools and API connections like the existing checks, and an organisation can write its own trust profile.
  • Because the rules and not the LLM weigh the evidence, the LLM can be exchanged without changing the verdict.
